# 💰 WageWise — Salary Prediction

**WageWise** is a machine learning project that predicts employee salaries based on various professional and demographic features. It helps job seekers, HR professionals, and organizations benchmark compensation more accurately using data-driven insights.

---

## 🌟 Features

- **Salary prediction** from input features such as experience, education, job role, and location
- **Data exploration & visualization** to understand what drives compensation
- **Multiple ML model comparisons** to identify the best-performing algorithm
- **Clean Jupyter Notebook** workflow — from raw data to final predictions

## 🚀 Getting Started

### Prerequisites

- Python 3.8+
- Jupyter Notebook or JupyterLab

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/samikshakamdi/WageWise-Salary-Prediction.git
   cd WageWise-Salary-Prediction
   ```

2. **Install required libraries**
   ```bash
   pip install pandas numpy scikit-learn matplotlib seaborn jupyter
   ```

3. **Launch the notebook**
   ```bash
   jupyter notebook WageWise.ipynb
   ```

## 🧠 How It Works

The notebook walks through a complete ML pipeline:

1. **Data Loading** — Import and inspect the salary dataset
2. **Exploratory Data Analysis (EDA)** — Understand distributions, correlations, and trends
3. **Preprocessing** — Handle missing values, encode categorical variables, scale features
4. **Model Training** — Train and compare multiple regression/classification models
5. **Evaluation** — Assess models using metrics like RMSE, MAE, and R²
6. **Prediction** — Generate salary predictions for new input data
